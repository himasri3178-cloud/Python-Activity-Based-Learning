# Python Activity-Based Learning

Complete Python solutions and full academic deliverables for **10 selected case studies** from the **Python Activity-Based Learning** curriculum.

## Syllabus Compliance
All Python implementations strictly adhere to the assigned syllabus without using out-of-scope constructs (no user-defined functions `def`, classes, dictionaries, sets, external libraries, or exception handlers):
- **Computational Thinking, Algorithms, Flowcharts & Pseudocode**
- **Variables, Data Types (`int`, `float`, `bool`, `str`) & Operators**
- **Conditional Statements (`if`, `elif`, `else`)**
- **Loops (`for`, `while`, `break`, `continue`, nested loops)**
- **Strings & Pattern Generation**
- **Lists & Nested Lists (2D matrices)**
- **Tuples, Tuple Operations & Tuple Unpacking**

## Mandatory Deliverables Included Per Case Study
Each folder `case_study_XX_<topic>/` contains:
1. **Problem Statement** (`README.md`)
2. **Objectives** (`README.md`)
3. **Assumptions** (`README.md`)
4. **Algorithm** (`README.md`)
5. **Flowchart** (`flowchart.png` + Mermaid diagram in `README.md`)
6. **Pseudocode** (`README.md`)
7. **Python Source Code** (`solution.py`)
8. **Test Cases** (`README.md` + embedded test scenarios in `solution.py`)
9. **Output Screenshots** (`output_screenshot.png` captured from Python 3.12 execution)
10. **Conclusion** (`README.md`)
